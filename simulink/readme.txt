IEEE 39-BUS FREQUENCY-RESPONSE SIMULATION

1. IEEE39_29VSG.slx
   Simulates the IEEE 39-bus system under sequential load increases
   to examine synchronization and its loss.

2. plot_VSG_frequency_paper_noinit.m
   Plots the simulated frequency responses corresponding to Fig. 2
   in the paper. The figure is saved in VSG_paper_figures.

Run the Simulink model first, then run the plotting program.
