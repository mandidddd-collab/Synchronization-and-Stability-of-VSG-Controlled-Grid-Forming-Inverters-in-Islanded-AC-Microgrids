CASE-STUDY CODE

The two MATLAB scripts contain all required network parameters.
No external parameter files or custom helper functions are required.

1. run_vsg_two_proposed_conditions_benchmark.m
   Computes and prints the four critical loading factors for six benchmark
   systems, corresponding to Table II.

2. draw_dominant_root_locus.m
   Computes the IEEE 39-bus eigenvalue loci under increasing loading and
   highlights the dominant poles, corresponding to Fig. 1.

3. IEEE39_29VSG.slx
   Simulates the IEEE 39-bus frequency responses under sequential load
   increases to examine synchronization and its loss, corresponding to Fig. 2.
